# Calculadora de Idade Gestacional

Calculadora simples de Idade Gestacional.

Dois métodos:

 -- Data da última menstruação
  
 -- Idade gestacional em Ecografia prévia
  
Transforma o resultado em texto simples para colar no PEC e-SUS

Objetivo: facilitar o trabalho dos profissionais da saúde no relatório em prontuário de Pré-Natal.
